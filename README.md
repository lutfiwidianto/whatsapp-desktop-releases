# 🟢 WhatsApp Web Pro (Multi-Akun & Anti-Not Responding)

Aplikasi container desktop resmi & modern untuk **WhatsApp Web** berbasis native C# & engine Chromium/Edge terakselerasi hardware. Dirancang khusus untuk mengatasi masalah klasik WhatsApp Desktop: freeze *"Not Responding"*, lag pencarian di grup besar, serta kebutuhan multi-akun bisnis/pribadi dalam satu komputer tanpa ribet.

---

## 🚀 Keunggulan Utama

* ⚡ **Anti-Freeze & Anti-Not Responding**: Menggunakan flag performa tinggi engine Chromium (`--disable-renderer-backgrounding`, `--disable-background-timer-throttling`, GPU Rasterization 60 FPS).
* 👥 **Multi-Akun Permanen (Isolated Profiles)**: Bebas menambah akun (Akun Reguler, Bisnis, CS Toko, Admin, dsb). Setiap akun memiliki folder profil terpisah sehingga sesi login QR tersimpan permanen dan **tidak akan pernah tertukar atau logout**.
* 🔍 **Pencarian Cepat di Grup Ribuan Pesan**: Bebas throttling memori sehingga pencarian chat riwayat lama tetap instan dan responsif.
* 🛡️ **Garansi Data Sesi Aman**: Update aplikasi hanya memperbarui binary executables. Direktori data profil (`%LOCALAPPDATA%\WhatsAppWebDesktop\Profiles\`) **dijamin 100% aman dan tidak akan hilang/logout** saat update!
* 🖥️ **UI Elegan & Collapsible Tab Bar**: Bilah tab atas yang manis dan modern, dapat disembunyikan/dimunculkan dengan satu klik (▲ / ▼) atau tombol `F11` untuk tampilan layar penuh.
* 📌 **Integrasi System Tray**: Jendela dapat diminimalkan ke System Tray dekat jam. Klik 'X' tidak sengaja tidak akan menutup sesi WhatsApp Anda.
* 🔄 **Sistem Force Update Otomatis**: Mendeteksi pembaruan penting secara otomatis sehingga pengguna selalu mendapatkan performa dan keamanan terbaik.

## 💡 Cara Penggunaan Singkat

1. **Unduh** salah satu file di atas (`WhatsApp_Setup.exe` atau `WhatsAppDesktop.exe`).
2. Jalankan aplikasinya dan scan QR code WhatsApp seperti biasa.
3. Untuk menambah akun kedua atau ketiga, klik tombol **`＋ Tambah Akun`** di bilah tab atas.
4. Klik 2x pada tab untuk mengubah nama akun sesuai keinginan Anda (misal: *CS Toko*, *Admin 1*).
5. Tekan **`F11`** atau tombol panah **`▲`** jika ingin menyembunyikan bilah navigasi atas (Full Screen).
